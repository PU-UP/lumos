## 在哪里体验

本机体验地址：http://127.0.0.1:8775/ 。页顶有黄色“体验版 · 使用模拟数据”提示。正式服务与正式记录保持原状。体验服务随本机进程运行，重启电脑后需重新启动，不是公开网站。

预置内容是明确标记的模拟资料与示例答复。新发送的消息由本机已登录 Codex 实际处理，会使用当前账户额度；任务更新只影响体验库。请勿把体验版当作正式工作入口。

## 与原系统的差异

| 原系统 | 本轮体验版 |
| --- | --- |
| 工作、对话、记录三个主入口 | Lumos、AIPM、Atlas（资料管理员）、Ops（仓库维护者）四个角色入口 |
| 在一段对话里逐轮切换角色 | 一段对话固定角色；换角色进入其独立历史和草稿 |
| 全站统一工作空间切换 | 新建对话明确资料范围，创建后固定；业务视图只保留本页资料筛选 |
| 对话主要依靠首条消息和历史恢复 | 可独立创建对话、改标题、保存工作备忘、结束和重开；备忘随对话供模型接续 |
| 任务、笔记、资料、运行记录按功能找 | AIPM 下找任务与人员，资料管理员下找笔记与资料，维护者下找运行问题 |

## 建议按这四条路径体验

1. **看入口是否直观**：打开首页，依次进入四个角色；确认每个角色的一句职责、相关功能和对话入口容易理解。原任务详情、笔记与处理经过仍可打开。
2. **看会不会串话**：进入 AIPM 的对话，选择“模拟 · 联调准备”，写一段草稿但不发送；切到资料管理员，看是否出现不同会话；再回 AIPM 并刷新，草稿应保留。每个角色已有两段示例对话，可来回切换。
3. **看能否继续上次的事**：新建一段对话，填标题并确认资料范围；打开右上角“管理对话”，写下目标和未完成事项并保存。发送“仅讨论，不更新工作记录：请概括本对话的目标与未完成事项”，检查答复是否准确；普通讨论不显示重复回执，确有更新才显示保存结果。可以改标题、结束对话，再重新打开。
4. **看业务入口是否还顺手**：到 AIPM 的任务页查看模拟任务；到资料管理员的笔记页打开模拟评审笔记；到维护者的运行问题页查看处理历史。不要求实际修改正式业务。

反馈重点：是否知道该找谁、切换是否迷路、是否需要重复解释背景、备忘是否有用、原操作是否变难。阶段一验收后再进入职责交接闭环，不提前加入主动巡检。
