## 使用边界

- 日常入口仍是本项目中的 Agent 对话与本地工具，没有独立应用、后台记忆进程或手机编辑端。保存与备份时暂停人工编辑／自动保存。
- Notion、HTML、云同步及自动备份尚未实现。Notion 后续只展示结论和必要进展，统一放在 Lumos Project 下，不维护第二套状态。
- 本机备份只覆盖已测试的误操作与迁移恢复；尚无独立设备／云端备份落点，不能承诺设备损坏后恢复。长期真实工作、断电和非 Windows 平台效果仍未验证。
- Git 已初始化并配置 origin；本轮保存本地提交，不代表代码已推送远程，更不代表工作数据上云。

## 后续维护方向

开始使用，无需再追加一轮框架设计。先围绕真实准备工作形成持续更新的方案、学习结论或资料清单，在下一次对话中直接接续；遇到遗漏、误解、检索或保存障碍时，在本项目内做最小修复。

优先观察：是否需要重复交代背景、重要理解有没有留下、纠正后是否继续误用旧结论、成果是否容易找到。不要以数据库记录数量代替工作效果。

独立数据备份应尽早补上，在将 Lumos 作为重要材料唯一存放处之前落实。稳定内容出现且确有跨设备阅读需求后，再建设 Notion 展示出口；不急于增加云数据库、复杂检索或平台能力。

外部 reviewer 本轮交接结束。普通维护、缺陷修复与渐进改进由 Lumos 项目内部负责；只有重大设计失误才重新发起外部评审。
