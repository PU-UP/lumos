# 统一工作区

2026-11-22，用户授权不再按灵光和仓库维护拆分入口。四角色保留，业务任务和仓库事项在同一工作区接续；原脉络仍说明各项工作的背景，不改为互不相通的项目入口。

`unify-workspace --quiet-files` 是显式分类迁移，须暂停全部写入、完成备份。内部统一沿用 `lingguang` 标识：更新原维护脉络的空间、旧处理记录的空间和版本号、人员可见范围、既有授权空间列表，并保存用户决定。任务字段、笔记正文、来源及旧版本不被重写。待处理输入或已有维护空间四角色聊天元数据会阻止此命令；应先处理在途工作，不能绕过聊天身份保护。正式旧库本次无该类聊天元数据，按先统一、后 `upgrade-roles` 的顺序执行。

统一决定持久保存后，服务启动读取该决定。网页不再显示两个空间选择或资料范围标签；旧 `workspace=lumos` 网址及请求在本机网页入口按统一工作区接续。未合并的数据根保持原行为。模型选择依旧按角色独立；原记录上下文、归档/删除确认和精确来源规则继续生效。

迁移通过现有 begin/commit 与版本历史保存，执行前校验完整候选、执行后读回；重复执行不再次改写。完成迁移后仍须将原 74 项任务、18 篇笔记、11 条主线及全部来源与切换前备份逐项核对，再启动后台。
