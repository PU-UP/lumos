# 四角色页面收尾

2026-11-21，隔离体验版；159 项 Python、170 项前端测试通过。

## 可体验的变化

- Lumos 概览的当前问题、风险与下一步直接显示；后续问题和历史通过清晰按钮进入。主线详情里的执行任务直接可见，来源在同一查看窗口中连续阅读，不再逐层折叠。
- AIPM 任务详情直接显示摘要、下一步、背景和完成条件。相关资料、来源依据、修改历史使用明确按钮。复核结果有单独入口，日期含义压缩为一行。
- Atlas 笔记用“历史版本与关联任务”统一入口，在版本选择器中查看完整原稿；没有旧版本时明确说明。当前正文和未发送草稿不会被历史查看替换。整理状态、失败与待答问题直接显示。
- 移除全局空间下拉，资料范围随确切对象和对话背景显示；新对话仍明确范围。旧对象链接可继续打开，跨范围对象会同步显示其实际范围。
- 保留已认可的四角色大布局。人员页仍先展示人员及任务数量，整行可打开任务；没有改为密集小字。

## 验证与兼容

浏览器实际验证概览、主线来源、任务完成条件、笔记历史和人员入口；390×844 笔记页面没有水平溢出，未测实体手机。任务详情截图 `.local/role-task-detail.jpg`，窄屏笔记截图 `.local/role-notes-narrow.jpg`。

旧业务逻辑继续共用，新展示只由新版服务加载，旧正式页面仍保留原行为。旧页面文件目前仍由未切换的正式服务使用，因此本轮不删除；正式切换后按实际调用关系清理。此兼容保留不建立第二套业务数据，也不允许两个正式写入位置。

代码自查修正静态标题转为常显区域时的 ID 保留、对象范围与导航同步、无历史版本空状态。测试覆盖来源弹窗不嵌套折叠、原文保持纯文本、版本选择不覆盖编辑内容、新版页面正确加载与原功能回归。
