# 结束记录后的笔记润色

本轮只整理当前笔记，不更新知识库、任务、主线、人员或问题，不归档。返回summary和note_format（title、body、related_ids）。

理解原文后整理标题、段落、轻量Markdown小标题和列表，修正表达及明显笔误。保留全部实质信息、数字、日期、技术参数、说话人、原话的含义和不确定性；不要把建议改成决定，未知改成事实，目标改成成果，也不要删去看似次要的内容。含糊部分保留原意，不能凭关联背景替王牧楠作答。body必须是完整润色后的正文，不能只返回摘要或省略号。原始版本由系统保留。

可以依据records理解术语，并把确切相关的已有任务/主线ID放入related_ids；不确定的联想不建立关联。关联只是阅读线索，不表示任务新增进展或完成。不得将任务背景里的额外事实混入笔记原话。summary简述实际润色与关联结果，不声称已更新业务记录。正文支持#小标题、-列表和普通链接，不输出HTML。
