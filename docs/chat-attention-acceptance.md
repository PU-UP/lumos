# 对话减负与主动消息体验

2026-11-22。仅体验版，不迁移正式工作记录、不启动正式服务。

## 如何体验

打开 http://127.0.0.1:8775/ 并刷新。确认页顶“体验版”标记。

1. 打开任一角色聊天。“切换对话”和“＋ 新对话”同级；新建后直接输入，不填写标题。旧草稿保留在原对话。
2. 新一轮处理完成后，Agent 自动维护简短名称、接续备忘和话题状态。点击顶部名称可重命名，只有一个名称输入框；手动名称不会被 Agent 改掉。话题告一段落仍可继续聊，不等于任务完成。
3. 点击大叉关闭聊天，回到原工作页。保留拖动宽度、模型偏好、草稿及切换角色后的恢复行为。
4. 点击右下角“消息”气泡，查看未读和已读话题。消息在原页面侧栏打开，不强制跳到其他角色工作页。切换到 Ops 的消息时，标题和输入对象明确显示 Ops。
5. 消息末尾进入可见区域并停留约 1.2 秒后自动已读；后台页面、收起的聊天和未滚动到的内容不算已读。已读不代表回答或解决，已接续的话题也保留在消息列表中。点击“答复”可携带确切问题或故障来源，输入说明后发送。

## 与原版的差异

取消“管理对话”“保存对话信息”“结束这段对话”以及新建时的命名表单。对话列表直接显示未读、处理中、可继续聊等状态。备忘交给 Agent 接续，不要求使用者维护。

主动消息来自已保存的真实待答问题、到期跟进、Lumos 决定后的重要更新和 Ops 运行报告。AIPM/Atlas 先向 Lumos 汇报，业务主动追问由 Lumos 发出；Ops 独立汇报系统异常。普通回复可以在各自对话中提示未读，不等于专业角色绕过 Lumos 主动安排业务。

有确切来源关联时继续已有话题，否则建立对应角色对话；相同消息不因轮询或重启再次变成未读。剩余问题、诊断或恢复状态有实质变化时保留旧消息并送达新内容。已读只记录确切消息 ID，不能顺带吞掉同时到达的新消息。

## 自行 review 与验证

- 按单用户本地服务检查调用链、权限、保存、失败重试、历史兼容和浏览器实际布局；无新增第三方依赖。
- 标题、备忘及普通回复已读凭据随本轮业务回执原子保存。新消息沿用既有版本化会话和备份，不另建数据库。旧调用方未返回新备忘时保留原备忘；人工改名期间生成的旧标题不能覆盖人工选择。
- 历史消息保留原文和来源，后续任务转移资料范围不改写或阻止历史记录；新消息仍严格核对范围。读回、重试和读取来源不能越过角色权限。
- 前端测试覆盖直接新建、旧草稿、角色模型偏好、重命名冲突/响应丢失、确切问题答复、后台不误读和新消息不被旧已读请求吞掉。
- 后端测试覆盖真实协作链中的 AIPM → Lumos 追问、去重、读后问题仍未解决、到期/未来跟进、Ops 路由、范围拒绝、原子失败、手动名称保护、旧备忘保护及来源转移后的历史保留。

## 边界

主动消息由服务运行时接续已有记录，服务停机期间不假装检查或发消息；恢复后合并接续。没有新增外部通知、任意系统监控或自动提权。旧历史没有已读凭据时只显示“已保存对话”，不伪造曾经读过；不把旧普通回复批量标成新消息。模型未提供具体型号时保留“具体型号未记录”，不猜型号。
