# 精简工作区体验与验收

2026-11-22。按王牧楠认可的方向完成实现与自行 review，供体验；不代为确认用户验收。全部浏览器操作使用 8775 的隔离模拟库，正式 8765 服务未重启，正式工作记录未迁移。

## 怎么体验

打开 <http://127.0.0.1:8775/>，刷新已打开的旧页面。页顶应显示“体验版 · 使用模拟数据，与正式工作记录隔离”。

1. **Lumos：先看当前重点。** 每条主线或独立事项集中呈现时间、当前情况或待答问题。同一任务不再同时复制到“关键问题”“近期节点”“主线进展”等多个区块。点击“答复”可直接回应原问题，点击事项标题可查看完整背景。
2. **随时聊。** 点击右下角“和 Lumos 聊”，在侧栏继续当前对话；“切换对话”可查看历史或新建对话。收起后继续看工作，重新打开保留草稿。窄屏用全宽对话，收起后回到原页面。AIPM、Atlas、Ops 均有对应入口和原有职责专属开场。
3. **AIPM：看任务。** 任务字段继续直接编辑，列表中用简短提示标识需答问题；完整问题在 Lumos 中答复。“筛选与视图”集中容纳状态、项目标签、时间范围、近期安排、人员与阶段交付入口。修改这些筛选后，入口显示“已筛选”。
4. **Atlas：看笔记与资料。** 同一页查看当前笔记、项目文件及文件是否登记/解析；查找关键词可搜索正文。勾选“包含已归档内容”后保留当前笔记，并加入归档笔记。“写笔记”直接进入新笔记编辑，文件的固定版本和登记仍可操作。
5. **Ops：看当前异常。** 首页保留问题、影响和状态，已恢复/复查无异常的旧问题进入处理历史。完整诊断通过“诊断与建议”查看，诊断不等于修复。

“工作回报”原本表示角色交接和操作结果记录，属于系统协作信息。现在取消该常驻栏目；保存结果留在原对话和具体事项中，Lumos 页的“答复记录”仅供追溯。
