## 第一批实现指示

1. 实现简短 Agent 入口、最小本地工具和数据结构，覆盖创建／读取脉络、记录依据与行动、保存文档、判断纠正、必要历史与引用。
2. 实现设计中的候选保存与读回机制、完整备份恢复及迁移接管／取消；普通实现选择自行决定，不扩展通用框架。
3. 以入职准备作为真实背景。建图定位的模拟决定、行动、实验及故障测试放入隔离测试数据，不能写成用户已经发生的工作。
4. 运行第 10 节本地验收，保留可复现命令与实际结果。使用没有旧会话背景的新会话或独立 Agent 检查接续；若环境暂不具备，明确标为未验收，不用同一上下文自测替代。
5. 数据库、运行资料、候选、历史版本和备份不得进入 Git；实际数据根及新增运行目录应与忽略规则核对。Git 忽略不等于数据备份。
6. 本轮不建设 Notion 发布、HTML 阅读包、专用 UI、云共享数据库、后台任务或高级检索。独立备份落点未确定不阻止本地工具实现，但不能宣称已完成设备故障保障。

完成后提交实现摘要、使用入口、运行验收结果及未验证项，交回本 reviewer 做实现验收。不要只交付另一份计划。
